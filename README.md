# Banking-simulator
A digital banking simulator project built to explore full-stack application development and integration between frontend, backend, database, and containerization.

Tech Stack
Frontend: React, TypeScript, Tailwind CSS
Backend: Java, Spring Boot
Database: PostgreSQL
Containerization: Docker
API: REST API

#Project Overview

This project simulates a digital banking application with a React-based frontend and Spring Boot backend. The application uses PostgreSQL for data storage and includes Docker to explore containerized application deployment.

The project covers the integration between the frontend, backend, and database, with a focus on building a simple and structured banking application.
